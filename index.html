快速初始化

使用 agentkit init 命令，一键生成项目模板，内置多种应用类型（Basic App、Stream App等）

简洁的 SDK

基于装饰器的优雅 API，使用 @app.entrypoint 定义入口函数，专注业务逻辑开发

☁️

多种部署模式

支持 Local、Hybrid、Cloud 三种部署模式，灵活满足不同场景需求

🔧

交互式配置

使用 agentkit config 命令，引导式配置部署参数、环境变量和镜像仓库

📦

一键构建部署

agentkit launch 命令组合 build 和 deploy，自动完成构建镜像和部署到 Runtime
