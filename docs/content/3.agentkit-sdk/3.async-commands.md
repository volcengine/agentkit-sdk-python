# 异步 Shell 命令

`AgentkitToolsClient` 支持 `async_exec_command`、`view_async_command` 和
`delete_async_command`。这三个方法默认通过
`agentkit.<region>.volces.com` 调用数据面，使用 AK/SK 签名；现有 Tools
管理接口保持原有地址。可通过 `data_plane_host` 参数指定数据面主机名
（不含协议和路径）。其他云平台需要显式指定其支持这些接口的数据面地址。

```python
import time

from agentkit.sdk.tools.client import AgentkitToolsClient
from agentkit.sdk.tools.types import (
    AsyncExecCommandRequest,
    ViewAsyncCommandRequest,
    DeleteAsyncCommandRequest,
)

# 从环境或 SDK 凭据配置读取 AK/SK，也可显式传入 access_key / secret_key。
client = AgentkitToolsClient(region="cn-beijing")
session = {"tool_id": "t-your-tool", "user_session_id": "async-demo-001"}
task = client.async_exec_command(AsyncExecCommandRequest(
    **session, command="echo $USER_SESSION_ID", ttl=3600,
))
try:
    for _ in range(30):
        result = client.view_async_command(ViewAsyncCommandRequest(
            **session, task_id=task.task_id,
        ))
        if result.status == "completed":
            print(result.output, result.exit_code)
            break
        time.sleep(1)
finally:
    deleted = client.delete_async_command(DeleteAsyncCommandRequest(
        **session, task_id=task.task_id,
    ))
    print(deleted.deleted)
```

三个请求均需要 `tool_id`，并提供 `user_session_id` 或 `session_id` 中至少一个。
执行时必须提供 `command`，可选 `exec_dir` 和自定义 `task_id`；查询、删除时
必须传入执行接口返回的 `task_id`。

`ttl` 省略或为 `0` 时使用服务端默认值；显式正值范围为 60–86400 秒。
SDK 按既有模型约定检查必填字段和类型，会话标识组合与 TTL 范围由服务端校验，
错误通过现有 `ApiError` 机制返回。

删除只清理指定异步 Shell，不删除整个工具会话。Shell 已回收时，服务端仍返回
`Deleted: true`，重复删除成功。SDK 不会将其他 404 或资源错误一律当作成功。
